# Scope: Scouts BSA Merit Badge Counselor Workbench

## 1. Problem statement
Volunteer Scouts BSA Merit Badge Counselors typically spend 8 to 15 hours building slide decks, Scout workbooks, lesson plans, and parent prerequisite letters for each of the 144 official Merit Badges. Standard single-prompt LLM slide generators do a poor job on Merit Badges: they summarize requirements down to four generic bullets, cut off multi-part sub-requirements (`1a`, `1b`, `2b1`, `3a-3q`), mix up requirement years, and repeat the same stock diagram across slides.

This project builds a multi-agent curriculum workbench on the Google Agent Development Kit (ADK) for Python (`scouts-bsa-merit-badge-agent`). It generates widescreen (`16:9`) PowerPoint decks (`.pptx`), printable Scout workbooks (`.md`), session agendas, and Youth Protection (YPT) parent letters grounded in the official BSA Merit Badge Pamphlet:

1. **5-tier pamphlet and regional research (`src/agents/researcher.py`)**: Extracts the full requirement and sub-requirement tree verbatim from `scouting.org` and official BSA Pamphlet PDFs (`PyMuPDF`), locks the requirement wording with a SHA-256 hash (`compute_canonical_pamphlet_hash()`), classifies each requirement by how it is taught (`IN_CLASS_DISCUSSION`, `HANDS_ON_SKILL_STATION`, `PREREQUISITE_CAMPOUT_HOME`), and resolves the counselor's City, State, or 5-digit ZIP code (`resolve_counselor_location()`) across all 51 U.S. jurisdictions (`_STATE_CIVIC_AND_FIELD_REGISTRY`) to regional NOAA National Weather Service offices, local terrain hazards, and state agencies.
2. **12-archetype slide planner and unified visual pipeline (`src/agents/planner.py`, `src/agents/beautifier.py`, `src/tools/pptx_builder.py`)**: Maps each requirement onto 12 structured `python-pptx` layouts with `[SAY]`, `[DEMONSTRATE]`, and `[ASK SCOUTS]` teaching notes. Renders decks by default in the **Unified Warm Cream (`#FAF8F5`, `BEAUTIFIED`) Rich Visual Slide Theme** (`Visual Assets: 100% Pre-Cached (8-Bit PNG)` in the sidebar, with per-slide Card Style & Brand Palette pickers in Drawer Tab 2 and backward-compatible API enum support for `STANDARD` and `STUDIO`), preserves extracted BSA Pamphlet figures and 220-DPI technical diagrams (`src/tools/diagram_generator.py`), and attaches up to 20 pre-populated Nano Banana Hero Illustrations per deck at `$0.00` runtime cost (`NANO_BANANA_HERO`, with `3,917` built-in curated visual assets across all 144 Merit Badges: `1,306` compressed 8-bit Nano Banana PNGs + `2,323` 100%-Vision-verified BSA Pamphlet figures [`1,009` primary + `1,314` requirement alternates] + `144` emblems + `144` covers, while `FinOpsBudgetPlugin` caps live uncached image synthesis at 5 for `BEAUTIFIED` and 15 for `STUDIO`, with deterministic fallback to 220-DPI Scouts BSA EDGE Skill Concept Maps).
3. **Two-stage layout and safety check (`src/agents/reviewer.py`)**: Stage 1 checks `python-pptx` shape coordinates in memory in a single pass in under 10ms (`check_pptx_conformance()`) to catch Axis-Aligned Bounding Box (AABB) overlaps, text below `12.0pt`, WCAG contrast ratios below `4.5:1`, or duplicate images. Stage 2 verifies 100% requirement coverage and BSA Guide to Safe Scouting rules inside a bounded `LoopAgent` (`max_iterations=3`).
4. **Material 3 Counselor Workbench, In-App Documentation Viewer & Zero-PII Super-User Admin Console (`ui/` + `src/server.py` + `src/observability/telemetry_store.py`)**: Provides a responsive two-column FastAPI and Material 3 web application (`:8085`) with Server-Sent Events (SSE), A2UI v0.9 JSON payloads, a Top-Bar **`📘 Documentation`** button (`#btn-open-docs-viewer`, shortcut `D`) opening the **In-App Markdown Documentation Viewer** (Option A: Dual-Mode Material 3 Documentation Studio Modal with `📘 User Guide` preselected, `🛡️ Admin Guide`, and `⚙️ Engineering Docs (9)` toggle, live Mermaid diagrams, inline screenshots, and `↗ View on GitHub` links), a Footer **`GitHub`** link (`https://github.com/clayberg/scouts-bsa-merit-badge-agent`), a 144-Badge Visual Patch Gallery (`#patch-gallery-modal`) with a sticky filter header, 3 automatic Scout Slide Construction Animations during deck generation (including the Frame 4 helicopter hoist cable foreground overlay `iso_heavy_4_foreground_cable.png`), a Sticky Export Split-Button with the **Open in Google Slides: Account & Destination Modal (`#gslides-export-modal`)**, a consolidated `📥 Export & Print ▾` menu, **Centered Split-Screen Presenter View (`🪟 Presenter View` / `P`)** with 3 color-coded `[SAY]`, `[DEMONSTRATE]`, and `[ASK SCOUTS]` cards and a non-disruptive `↗ 2nd Monitor` floating teleprompter window, Centered Fullscreen Classroom Presentation Mode (`Present Fullscreen` / `F`), a Live Classroom & Skill Station Timer (`⏱️ Timer`), Interactive Quiz Reveal Mode (`Q`), an on-stage **Easy Slide Image Switcher** (`◀` / `(1/3) ▾` / `▶` visual pill and thumbnail/caption popover for cycling Vision-verified pamphlet alternates at `$0.00` cost), a 3-Tab Under-Stage Drawer (*Speaker Notes with FinOps Cost Transparency Gate Modal `#ai-polish-finops-modal` for `✨ AI Polish Slide` `~$0.0008` and `✨ Polish Entire Deck` `~$0.068` `[1/82]`*, *Customize Slide with 10 SVG Mini-Wireframe Archetype Cards & 4-Tab Image Studio*, and *Quick Edit Slide Text*), a Counselor Classroom & Field Toolkit (*`↓ Blue Card Tracker` jump button*, *Patrol Blue Card `#34124` & Scoutbook Plus Sign-Off Matrix with Bulk Roster Paste, CSV Import & Date Stamp*, *4-Sub-Tab StudioKit*, *`↓ Counselor Rating` jump button*, *Multi-Format Session Pacing Selector*, *Patrol Skill Station Rotator Matrix*, *Master Quartermaster Gear Checklist*, *Pre-Class Prerequisite Readiness Checklist*, *Printable 3x5 Counselor Pocket Cue Cards*, *One-Click Email/Gmail Parent Letter*, and *Print-Ready Scout Handouts*), and a The web slide preview and the downloaded `.pptx` file render identical text, card layouts, integrated `1.5pt` DrawingML card borders, de-boxed transparent pamphlet figures, and visual styling.

## 2. Target users
- **Primary**: Scouts BSA Merit Badge Counselors, Summer Camp Area Directors, and Merit Badge University (MBU) instructors.
- **Secondary**: Youth Patrol Leaders and Eagle Scout candidates preparing teaching sessions using the BSA EDGE Method (`Explain, Demonstrate, Guide, Enable`).
