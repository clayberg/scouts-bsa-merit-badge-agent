#### Req 4d(2): Sensor Logic Program Flowchart Development
**Official Requirement 4d(2):** Prepare a flowchart of the desired steps to program your robot for accomplishing the task in 4(a). Include procedures that show activities based on sensor inputs. Place this in your robot engineering notebook.
**Source:** *Official Scouting America Robotics Merit Badge Pamphlet (p. 32, p. 33)* • **Scout Workbook Organizer (Concept & Examples Notes):** Req 4d
- **Socratic Prompt (Ask Scouts First):** If your robot encounters a wall while driving forward, how does your flowchart show the decision it must make?
- **Official Pamphlet Summary & Expected Answer Key:**
  - Sensor Logic Program Flowchart Development: Standard flowchart symbols map program flow, using ovals for terminals, rectangles for processes, and diamonds for decision branches triggered by sensor data.
