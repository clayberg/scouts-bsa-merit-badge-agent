# Technical specification: Scouts BSA Merit Badge Counselor Workbench

## 1. Agent pipeline topology (`src/agents/`)
- **Root supervisor**: `MeritBadgeCoordinatorAgent` (`src/agents/coordinator.py`), configured with `EventsCompactionConfig(compaction_interval=5, overlap_size=2, compaction_strategy="additive")` and `ContextCacheConfig(ttl_seconds=3600, min_tokens=2048)`. Orchestrates 7 specialized sub-agents across the core curriculum pipeline and interactive Image Studio:
  1. **Research stage (`src/agents/researcher.py`)**:
     - `PamphletResearchAgent` (`LlmAgent`, `gemini-2.5-pro`): Extracts the requirement tree, pamphlet excerpts, and figures via `fetch_merit_badge_pamphlet_pdf()`.
     - `WebSearchGroundingAgent` (`LlmAgent` wrapped in `AgentTool`, `gemini-2.5-flash` + `GoogleSearchTool`): Grounds regional context via `enrich_requirements_with_deep_research()` and `resolve_counselor_location()` across all 51 U.S. jurisdictions (`_STATE_CIVIC_AND_FIELD_REGISTRY`), while verifying `compute_canonical_pamphlet_hash()` so official requirement text stays untouched.
     - `ResearchCoverageCriticAgent` (`LlmAgent`, `gemini-2.5-pro`): Runs `verify_subrequirement_coverage()` inside a bounded `LoopAgent` (`max_iterations=2`).
  2. **Planning and StudioKit stage (`src/agents/planner.py`, `src/tools/counselor_studiokit.py`)**:
     - `SlideContentPlannerAgent` (`LlmAgent`, `gemini-2.5-pro`): Runs `generate_slide_storyboard()` to map each requirement onto the 12 slide archetypes (`Standard Deck` 1-4 slides/req • 18-48 slides; `Deep Dive / Camp School Deck` 3-8 slides/req • 30-100+ slides), compiles Option C conversational first-person `[SAY]` speaking scripts with inline `[Stage Cues]`, selective `[DEMONSTRATE]` steps, and `[ASK SCOUTS]` questions ending with `[Expected Answer: ...]` (`_build_slide_teaching_notes()`), and builds the Counselor Session Agenda (`generate_counselor_session_agenda()`) and Parent Prerequisite Letter (`generate_prerequisite_parent_letter()`).
  3. **Slide theme and visual stage (`src/agents/beautifier.py`)**:
     - `SlideBeautifierAgent` (`LlmAgent`, `gemini-2.5-flash`): Runs `beautify_slide_storyboard()` to apply the **Unified Warm Cream (`#FAF8F5`, `WARM_CREAM` / `CREAM` default) Rich Visual Slide Theme** (`Visual Assets: 100% Pre-Cached (8-Bit PNG)` in the sidebar, with per-slide Card Style & Brand Palette overrides in Drawer Tab 2, modern API enum support for `CRISP_WHITE` / `WHITE` `#FFFFFF` and `DARK_SLATE` / `SLATE` `#0F172A`, and backward-compatible legacy enum aliases `BEAUTIFIED`, `STANDARD`, `STUDIO`), enforce consecutive-slide palette variety, preserve each slide's original graphic (`original_diagram_path`, `original_archetype`), and attach up to 20 pre-populated Nano Banana Hero Illustrations (`NANO_BANANA_HERO`, with `3,917` built-in curated assets across all 144 badges: `1,306` compressed 8-bit PNGs cached in `assets/ai_illustrations/` + `2,323` 100%-Vision-verified BSA Pamphlet figures [`1,009` primary + `1,314` requirement alternates] in `assets/pamphlet_images/` + `144` emblems + `144` covers at `$0.00` runtime cost, while `FinOpsBudgetPlugin` caps live uncached image synthesis at 5 for `WARM_CREAM` and 15 for `DARK_SLATE`, with deterministic fallback to 220-DPI Scouts BSA EDGE Skill Concept Maps via `generate_ai_editorial_illustration()`) on eligible slides without overwriting existing technical diagrams.
  4. **Interactive Merit Badge Image Studio & Easy Slide Image Switcher (`src/agents/image_studio.py`)**:
     - `WebImageSearchAgent` (`LlmAgent`, `gemini-2.5-flash`): Populates per-slide `slide_image_choices` (primary figure plus up to 2 Gemini Vision-verified BSA pamphlet alternates with cached captions) via `seed_badge_image_catalog_from_storyboard()` to drive the on-stage **Easy Slide Image Switcher** (`#stage-visual-source-badge` and `#stage-visual-pill-popover` for 1-click `◀` / `▶` cycling and thumbnail/caption comparison at `$0.00` token cost). Searches live Wikimedia Commons for up to 12 public-domain educational photos and diagrams via `search_web_images_for_slide()`, manages local file uploads via `upload_custom_slide_image()` (`USER_UPLOAD`, `$0.00 USD`), clears user-searched web and user-created AI cache entries via `purge_cached_web_and_ai_images()` (preserving `PAMPHLET`, `NANO_BANANA_HERO`, and `USER_UPLOAD` entries), and batch-indexes images per merit badge in `assets/badge_image_catalog/<badge_slug>/` and SQLite (`badge_image_catalog`).
     - `NanoBananaImageAgent` (`LlmAgent`, `gemini-2.5-flash-image` / Nano Banana & Vertex AI Imagen 3): Estimates image generation cost (`estimate_nano_banana_image_cost()`, `$0.08 USD` per live on-demand image, ~2,580 tokens; `$0.00` for pre-bundled catalog visuals), requires explicit user consent (`user_consented=True`), generates custom 220-DPI text-free slide visuals across 10 UI style options (`8` artistic styles + `Auto (Content-Aware Mix)` via `resolve_content_aware_visual_config()` + `4-Quadrant Concept Map`, plus 4 legacy aliases: `Photorealistic Image`, `4-Quadrant Concept Map`, `Watercolor Field Sketch`, `Line Drawing`, `Cartoon Drawing`, `Technical Diagram`, `3D Isometric Illustration`, `Editorial Vector Illustration`, and `Vintage Merit Badge Poster`) with explicit `include_humans` control (Scouts BSA Field Uniforms vs. zero human figures), and runs `verify_generated_image_matches_prompt()` to confirm prompt alignment.
  5. **Human-in-the-loop confirmation gate (`src/tools/hitl_confirm.py`)**:
     - `request_counselor_confirmation()` and `verify_hitl_before_tool_callback()` issue and verify an HMAC-SHA256 `HITLConfirmationToken` before building the `.pptx` file.
  6. **PowerPoint build, Hybrid PowerPoint Template Engine, Global Deck Layout Style Engine (`DeckStyleConfig`), and review loop (`src/agents/builder.py`, `src/agents/reviewer.py`, `src/tools/template_engine.py`)**:
     - `PowerPointBuilderAgent` (`gemini-2.5-flash`): Calls `generate_bsa_slide_deck_pptx()` (`src/tools/pptx_builder.py`) to build the `16:9` widescreen `.pptx` presentation (`<Badge>_<Tier>_<Depth>_Merit_Badge_Deck.pptx`), applying the active **PowerPoint Template & Custom Slide Theme (`src/tools/template_engine.py`)** across 17 built-in council-neutral Scouting America & Heritage templates across 7 Style Families (`bsa_scouting_america` default, `default_workbench`, `scouting_america_250`, `scouting_america_forest_sunrise`, `scouting_america_topographic`, `scouting_america_high_adventure_rock`, `classic_outdoor_silhouette_navy`, `classic_fleur_crimson_crest`, `wilderness_camp_timber`) or custom uploaded/URL-imported `.pptx`/`.ppt`/`.png`/`.jpg`/`.webp` templates with true responsive `SafeCanvasBounds` (`content_bottom_max_in <= 6.54"` clamping), auto-contrasted luminance footer text left-shifted clear of the corner logo (`0.55" .. 10.65"`), `MATCH_TEMPLATE` brand palette extraction, and the **Global Deck Layout Style Engine (`DeckStyleConfig` & `resolve_effective_slide_style()`)** supporting `CLEAN_OPEN`, `LEFT_ACCENT_LINE`, and `BOXED_CARDS`.
     - `BSABrandAndSafetyReviewAgent` (`gemini-2.5-pro` inside `LoopAgent`, `max_iterations=3`): Calls `check_pptx_conformance()` (single-pass `<10ms` AABB geometry verified against template `SafeCanvasBounds`, `12.0pt` minimum font size floor, WCAG contrast, image SHA-256 uniqueness), `audit_deck_visual_quality()` (Stage-2 visual quality auditing for `visual_quality_score >= 90`, `box_density_ratio`, and `whitespace_ratio`), and `validate_presentation_deck()`.
  7. **Official Scouts BSA Workbench MCP Server (`src/mcp_server.py`, [`docs/MCP_SERVER_INTEGRATION_GUIDE.md`](docs/MCP_SERVER_INTEGRATION_GUIDE.md))**:
     - Exposes `12` MCP Tools, `6` `bsa://` Resources, and `4` Guided Prompts over dual transport: Stdio (`scouts-bsa-mcp` CLI) and Streamable HTTP / JSON-RPC 2.0 (`POST /mcp`, `GET /mcp/info`, `GET /mcp/sse`), paired with the in-app **`🤖 MCP Hub`** modal (`#mcp-hub-modal`, shortcut `M`) and expanded full-height **Interactive MCP Playground (`[📊 Visual Card Preview | { } Raw JSON-RPC 2.0]`)** across all 22 capabilities.

## 2. Data contracts & persistent storage (`src/schemas.py`, `src/memory/session_store.py`, `src/observability/telemetry_store.py`)
- **Pydantic v2 models**: `MeritBadgeResearchRequest`, `MeritBadgeResearchResult`, `DeepResearchEnrichmentResult`, `DeckVisualBlueprint`, `SlideBeautificationSpec`, `DeckStyleConfig`, `FinOpsCostEstimate`, `BadgeImageEntry`, `ImageGenerationCostEstimate`, `PowerPointBuildRequest`, `PowerPointBuildResult`, `SlideSpec`, `ConformanceReport`, `VisualCritiqueVerdict`, `HITLConfirmationToken`, `A2UIMessageEnvelope`, `GuidedToolError`, `SlideTemplateSpec`, `SafeCanvasBounds`, and `CounselorWorkspaceRecord`.
- **SQLite tables (`scouts_bsa_sessions.db` & `scouts_bsa_telemetry.db`)**: **8 tables** in `scouts_bsa_sessions.db` (`counselor_sessions` for session state & telemetry, `pamphlet_vector_memory` for hybrid BM25 + vector chunks, `hitl_feedback` for counselor ratings, `badge_image_catalog` for cached per-badge images with SHA-256 deduplication, `polished_speaker_notes` for content-addressed SHA-256 cached Option C Layer 2 AI-polished counselor speaking scripts, `compliance_attestation_ledger` for immutable SHA-256 YPT/requirement attestation records, `counselor_workspaces` for saved multi-badge decks, section clones, Camp Week / Midway tags, and isolated Patrol Blue Card `#34124` rosters, and `counselor_favorites` for starred Merit Badges); plus `ZeroPiiTelemetryStore` tables `telemetry_deck_runs`, `telemetry_image_swaps`, and `telemetry_stage_latencies` in `scouts_bsa_telemetry.db` with recursive `scrub_pii_dict()` enforcement.
- **Counselor profile cache & PII isolation**: Local runs cache counselor contact info in `.cache/counselor_profile.json` (`0600` owner-only permissions, git-ignored); multi-tenant Cloud Run deployments persist contact info in client-side browser `localStorage` (`scouts_bsa_counselor_profile_v1`). Contact PII is injected locally into Slide 1 and the Parent Letter and scrubbed (`scrub_pii_before_sink()` and `scrub_pii_dict()`) before any LLM prompt or telemetry sink.
