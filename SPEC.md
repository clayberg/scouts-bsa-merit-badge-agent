# Technical specification: Scouts BSA Merit Badge Counselor Workbench

## 1. Agent pipeline topology (`src/agents/`)
- **Root supervisor**: `MeritBadgeCoordinatorAgent` (`src/agents/coordinator.py`), configured with `EventsCompactionConfig(compaction_interval=5, overlap_size=2, compaction_strategy="additive")` and `ContextCacheConfig(ttl_seconds=3600, min_tokens=2048)`. Orchestrates 7 specialized sub-agents across the core curriculum pipeline and interactive Image Studio:
  1. **Research stage (`src/agents/researcher.py`)**:
     - `PamphletResearchAgent` (`LlmAgent`, `gemini-2.5-pro`): Extracts the requirement tree, pamphlet excerpts, and figures via `fetch_merit_badge_pamphlet_pdf()`.
     - `WebSearchGroundingAgent` (`LlmAgent` wrapped in `AgentTool`, `gemini-2.5-flash` + `GoogleSearchTool`): Grounds regional context via `enrich_requirements_with_deep_research()` and `resolve_counselor_location()` across all 51 U.S. jurisdictions (`_STATE_CIVIC_AND_FIELD_REGISTRY`), while verifying `compute_canonical_pamphlet_hash()` so official requirement text stays untouched.
     - `ResearchCoverageCriticAgent` (`LlmAgent`, `gemini-2.5-pro`): Runs `verify_subrequirement_coverage()` inside a bounded `LoopAgent` (`max_iterations=2`).
  2. **Planning and StudioKit stage (`src/agents/planner.py`, `src/tools/counselor_studiokit.py`)**:
     - `SlideContentPlannerAgent` (`LlmAgent`, `gemini-2.5-pro`): Runs `generate_slide_storyboard()` to map each requirement onto the 12 slide archetypes (`Standard Deck` 1-4 slides/req • 18-48 slides; `Deep Dive / Camp School Deck` 3-8 slides/req • 30-100+ slides), compiles Option C conversational first-person `[SAY]` speaking scripts with inline `[Stage Cues]`, selective `[DEMONSTRATE]` steps, and `[ASK SCOUTS]` questions ending with `[Expected Answer: ...]` (`_build_slide_teaching_notes()`), and builds the Counselor Session Agenda (`generate_counselor_session_agenda()`) and Parent Prerequisite Letter (`generate_prerequisite_parent_letter()`).
  3. **Visual polish stage (`src/agents/beautifier.py`)**:
     - `SlideBeautifierAgent` (`LlmAgent`, `gemini-2.5-flash`): Runs `beautify_slide_storyboard()` to apply `STANDARD`, `BEAUTIFIED`, or `STUDIO` themes, enforce consecutive-slide palette variety, preserve each slide's original graphic (`original_diagram_path`, `original_archetype`), and attach up to 20 pre-populated Nano Banana Hero Illustrations (`NANO_BANANA_HERO`, with `3,917` built-in curated assets across all 144 badges: `1,306` compressed 8-bit PNGs cached in `assets/ai_illustrations/` + `2,323` 100%-Vision-verified BSA Pamphlet figures [`1,009` primary + `1,314` requirement alternates] in `assets/pamphlet_images/` + `144` emblems + `144` covers at `$0.00` runtime cost, while `FinOpsBudgetPlugin` caps live uncached image synthesis at 5 for `BEAUTIFIED` and 15 for `STUDIO`, with deterministic fallback to 220-DPI Scouts BSA EDGE Skill Concept Maps via `generate_ai_editorial_illustration()`) on eligible slides without overwriting existing technical diagrams.
  4. **Interactive Merit Badge Image Studio & Easy Slide Image Switcher (`src/agents/image_studio.py`)**:
     - `WebImageSearchAgent` (`LlmAgent`, `gemini-2.5-flash`): Populates per-slide `slide_image_choices` (primary figure plus up to 2 Gemini Vision-verified BSA pamphlet alternates with cached captions) via `seed_badge_image_catalog_from_storyboard()` to drive the on-stage **Easy Slide Image Switcher** (`#stage-visual-source-badge` and `#stage-visual-pill-popover` for 1-click `◀` / `▶` cycling and thumbnail/caption comparison at `$0.00` token cost). Searches live Wikimedia Commons for up to 12 public-domain educational photos and diagrams via `search_web_images_for_slide()`, manages local file uploads via `upload_custom_slide_image()` (`USER_UPLOAD`, `$0.00 USD`), clears user-searched web and user-created AI cache entries via `purge_cached_web_and_ai_images()` (preserving `PAMPHLET`, `NANO_BANANA_HERO`, and `USER_UPLOAD` entries), and batch-indexes images per merit badge in `assets/badge_image_catalog/<badge_slug>/` and SQLite (`badge_image_catalog`).
     - `NanoBananaImageAgent` (`LlmAgent`, `gemini-2.5-flash-image` / Nano Banana & Vertex AI Imagen 3): Estimates image generation cost (`estimate_nano_banana_image_cost()`, `$0.08 USD` per live on-demand image, ~2,580 tokens; `$0.00` for pre-bundled catalog visuals), requires explicit user consent (`user_consented=True`), generates custom 220-DPI text-free slide visuals across 10 UI style options (`8` artistic styles + `Auto (Content-Aware Mix)` via `resolve_content_aware_visual_config()` + `4-Quadrant Concept Map`, plus 4 legacy aliases: `Photorealistic Image`, `4-Quadrant Concept Map`, `Watercolor Field Sketch`, `Line Drawing`, `Cartoon Drawing`, `Technical Diagram`, `3D Isometric Illustration`, `Editorial Vector Illustration`, and `Vintage Merit Badge Poster`) with explicit `include_humans` control (Scouts BSA Field Uniforms vs. zero human figures), and runs `verify_generated_image_matches_prompt()` to confirm prompt alignment.
  5. **Human-in-the-loop confirmation gate (`src/tools/hitl_confirm.py`)**:
     - `request_counselor_confirmation()` and `verify_hitl_before_tool_callback()` issue and verify an HMAC-SHA256 `HITLConfirmationToken` before building the `.pptx` file.
  6. **PowerPoint build and review loop (`src/agents/builder.py`, `src/agents/reviewer.py`)**:
     - `PowerPointBuilderAgent` (`gemini-2.5-flash`): Calls `generate_bsa_slide_deck_pptx()` (`src/tools/pptx_builder.py`) to build the `16:9` widescreen `.pptx` presentation (`<Badge>_<Tier>_<Depth>_Merit_Badge_Deck.pptx`).
     - `BSABrandAndSafetyReviewAgent` (`gemini-2.5-pro` inside `LoopAgent`, `max_iterations=3`): Calls `check_pptx_conformance()` (single-pass `<10ms` AABB geometry, `12.0pt` minimum font size floor, WCAG contrast, image SHA-256 uniqueness) and `validate_presentation_deck()`.

## 2. Data contracts & persistent storage (`src/schemas.py`, `src/memory/session_store.py`, `src/observability/telemetry_store.py`)
- **Pydantic v2 models**: `MeritBadgeResearchRequest`, `MeritBadgeResearchResult`, `DeepResearchEnrichmentResult`, `DeckVisualBlueprint`, `SlideBeautificationSpec`, `FinOpsCostEstimate`, `BadgeImageEntry`, `ImageGenerationCostEstimate`, `PowerPointBuildRequest`, `PowerPointBuildResult`, `SlideSpec`, `ConformanceReport`, `VisualCritiqueVerdict`, `HITLConfirmationToken`, `A2UIMessageEnvelope`, and `GuidedToolError`.
- **SQLite tables (`scouts_bsa_sessions.db` & `scouts_bsa_telemetry.db`)**: `counselor_sessions` (session state & telemetry), `pamphlet_vector_memory` (hybrid BM25 + vector chunks), `hitl_feedback` (counselor ratings), `badge_image_catalog` (cached per-badge images with SHA-256 deduplication), `polished_speaker_notes` (content-addressed SHA-256 cache for Option C Layer 2 AI-polished counselor speaking scripts), and `compliance_attestation_ledger` (immutable SHA-256 YPT/requirement attestation records) in `scouts_bsa_sessions.db`; plus `ZeroPiiTelemetryStore` tables `telemetry_deck_runs`, `telemetry_image_swaps`, and `telemetry_stage_latencies` in `scouts_bsa_telemetry.db` with recursive `scrub_pii_dict()` enforcement.
- **Counselor profile cache & PII isolation**: Local runs cache counselor contact info in `.cache/counselor_profile.json` (`0600` owner-only permissions, git-ignored); multi-tenant Cloud Run deployments persist contact info in client-side browser `localStorage` (`scouts_bsa_counselor_profile_v1`). Contact PII is injected locally into Slide 1 and the Parent Letter and scrubbed (`scrub_pii_before_sink()` and `scrub_pii_dict()`) before any LLM prompt or telemetry sink.

## 3. HTTP, SSE, A2A, and Super-User Admin endpoints (`src/server.py`, `79` OpenAPI 3.1 paths in `docs/openapi.yaml`)
- `GET /health` and `GET /readiness`: Container liveness and deep dependency readiness checks.
- `GET /.well-known/agent.json`: A2A 1.0 Agent Card discovery.
- `POST /a2a/tasks/send`, `GET /a2a/tasks/{task_id}`, `POST /a2a/tasks/{task_id}/cancel`: A2A 1.0 task endpoints returning A2UI v0.9 surface envelopes.
- `GET /api/badges` and `GET /api/v1/badges`: Lists all 144 official Scouts BSA Merit Badges with category, Eagle status, and pamphlet/DRG URLs.
- `GET /api/counselor-profile`, `POST /api/counselor-profile`, `DELETE /api/counselor-profile`: Reads, saves, or clears the local counselor profile cache (`.cache/counselor_profile.json`) when running locally (returns a no-op indicator on multi-tenant Cloud Run so browser `localStorage` handles persistence).
- `POST /api/workflow/run` and `POST /api/v1/workflow/run`: Runs the full workflow (`badge_name`, `depth_mode`, `beautification_tier`, `enable_deep_research`, `audience_level`, `counselor_name`, `troop_affiliation`, `location_or_zip`, `email_address`, `phone_number`, `custom_troop_logo_path`).
- `GET /api/workflow/stream` and `GET /api/v1/workflow/stream`: Streams Server-Sent Events (`text/event-stream`) as each agent stage completes.
- `POST /api/slide/regenerate` and `POST /api/v1/slide/regenerate`: Updates a single slide's layout archetype, card theme, color palette, right-side graphic (`keep_current`, `restore_original`, `ai_hero`, `custom_image`, or `none` with automatic full-width layout reflow), or inline text overrides (`title_override`, `bullet_points_override`, `visual_caption_override`, `speaker_notes_override` at `$0.00 USD` cost), automatically re-syncs `presenter_notes` to the updated visual caption/cards, and rebuilds the `.pptx` file in place.
- `POST /api/slide/polish-notes` and `POST /api/v1/slide/polish-notes`: Option C Layer 2 on-demand Studio speaker-script polish endpoint backed by the SQLite `polished_speaker_notes` cache and optional in-place `.pptx` rebuild.
- `GET /api/badge/images` and `DELETE /api/badge/images` (plus `GET /api/v1/cache/clear`): Lists all cached images in the Merit Badge Image Catalog (`BadgeImageEntry` list) or purges user web-searched (`WEB_IMAGE_SEARCH`) and user AI-generated (`NANO_BANANA_AI`) cache items while preserving `PAMPHLET`, `NANO_BANANA_HERO`, and `USER_UPLOAD` entries.
- `POST /api/slide/search-web-images`: Invokes `WebImageSearchAgent` to find up to 12 live Wikimedia Commons images, download, and cache educational images for a slide.
- `POST /api/slide/estimate-image-cost`: Returns a FinOps cost estimate (`$0.08 USD` per image, ~2,580 tokens) before invoking `NanoBananaImageAgent`.
- `POST /api/slide/generate-nano-banana-image`: Invokes `NanoBananaImageAgent` (`visual_style` / `style_preset` across 10 UI style options plus 4 legacy aliases, including `Auto (Content-Aware Mix)` and `include_humans: Optional[bool]`) after verifying `user_consented=True`, verifies prompt alignment (`verify_generated_image_matches_prompt()`), attaches the image to the slide (adjusting text-only slides to `SPLIT_VISUAL_EXPLAINER`), and rebuilds the `.pptx` file.
- `POST /api/slide/upload-image` (`POST /api/v1/slide/upload-image`, `POST /api/badge/images/upload`): Validates and normalizes a user-uploaded `.png`/`.jpg`/`.webp` image (`<= 10 MB`, `$0.00 USD`), registers it in the badge catalog as `USER_UPLOAD`, and optionally applies it to the slide and rebuilds the `.pptx` file.
- `POST /api/studiokit/agenda` (`POST /api/v1/studiokit/agenda`) and `GET /api/local-grounding/senators` (`GET /api/v1/local-grounding/senators`): Dynamically regenerates the Counselor Session Agenda for a selected schedule format (`3 Troop Meetings`, `Summer Camp Week`, `Saturday Merit Badge Clinic`, `Weekend Campout Practicum`) and resolves current state U.S. Senators for civic badges.
- `POST /api/hitl/confirm` and `POST /api/v1/hitl/confirm`: Validates counselor approval and issues an HMAC-SHA256 `confirmation_token`.
- `POST /api/v1/feedback`: Records counselor ratings and requirement verification sign-off.
- `GET /api/v1/metrics` and `GET /api/v1/prompts/manifest`: Returns runtime latency percentiles, circuit breaker states, compliance audit logs, and prompt SHA-256 hashes.
- `GET /api/admin/status`, `POST /api/admin/auth`, `POST /api/admin/logout` (plus `/api/v1/admin/*` aliases): Dual-mode Super-User Admin authentication (`verify_admin_superuser()` in `src/security.py`, supporting local workstation auto-unlock, Cloud IAP `ADMIN_ALLOWED_EMAILS`, and `ADMIN_SUPERUSER_TOKEN` / `BSA_ADMIN_KEY` with `HttpOnly` cookie session).
- `GET /api/admin/catalog/{badge_name}`, `PUT /api/admin/catalog/image`, `POST /api/admin/catalog/promote-primary`, `POST /api/admin/catalog/recaption-vision`, `POST /api/admin/catalog/replace-image` (plus `/api/v1/admin/*` aliases): Super-User Admin 144-badge catalog curation endpoints for inline caption editing, promoting alternates to Primary, Gemini Vision re-captioning, and quantized 8-bit PNG image replacement (`docs/ADMIN_GUIDE.md`).
- `GET /api/admin/telemetry/summary`, `GET /api/admin/diagnostics`, `POST /api/admin/cache/reload` (plus `/api/v1/admin/*` aliases): Aggregated zero-PII usage, stage latency, and Easy Slide Image Switcher swap leaderboard telemetry (`ZeroPiiTelemetryStore`), 144-badge asset health matrix, and zero-downtime in-memory cache reload.
- `GET /api/deliverables/{filename}`: Serves generated `.pptx` decks, `.md` workbooks, and cached badge images with `Cache-Control: no-store`.
