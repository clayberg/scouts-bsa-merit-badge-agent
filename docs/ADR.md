## 2. `ADR-11`: Deferred Enterprise Components, Argolis Sandbox Constraints & As-Built Reconciliation Matrix

To guarantee **zero spec-vs-code drift** (Rubric B2.2 & B2.5), the table below reconciles every capability active and verified in the repository today against enterprise controls deferred to Phase 2 due to single-project Argolis sandbox constraints:

| Architectural Layer | Active & Verified in Repository / Demo Today (`src/`, `terraform/`, `tests/`) | Enterprise Cloud / Phase 2 Target Scope (Deferred / Sandbox Constraint) |
| :--- | :--- | :--- |
| **Session & Vector Persistence** | **SQLite WAL (`scouts_bsa_sessions.db`, 9 tables, `1.8ms` Hybrid BM25 + 768-dim Vector RRF)** active by default for zero-cost local and single-instance Cloud Run (`min-instances=1`) execution, paired with **`CloudSQLPgVectorBackend`** adapter (`src/memory/session_store.py`) and Terraform Cloud SQL PostgreSQL 16 (`terraform/main.tf`). | Multi-region active-active **Cloud SQL for PostgreSQL 16 (`pgvector` HNSW)** with read replicas across 10+ horizontal Cloud Run instances (`DATABASE_URL` cutover). |
| **Safety, Model Armor & Bidirectional PII Redaction** | **Bidirectional `ScoutsBSAModelArmorPlugin` (`src/agents/guardrails.py`)** scrubbing PII on user ingress, tool arguments, model responses, and outbound SSE streaming thought/progress payloads (`scrub_pii_from_structure()`), with REST client hook for regional Google Cloud Model Armor (`MODEL_ARMOR_TEMPLATE_ID`). | Organization-level **Google Cloud DLP inspection templates** and regional **Model Armor inspection endpoints** enforced via centralized Security Command Center policy. |
| **Evaluation & 5% Online Production Sampling** | **12-Badge Golden Dataset Evaluation Suite (`scripts/run_eval.py` / `scripts/eval_gate.py`, `Recall@3 = 1.0000`)** + **`OnlineProductionAuditSampler` (`src/observability/online_audit_sampler.py`)** sampling 5% of production traces after PII scrubbing + **Honest Dual Latency Telemetry (`first_status_event_ms` vs. `true_first_content_token_ms`)**. | Automated **Cloud Logging sink export to BigQuery** with scheduled Vertex AI Evaluation Service drift dashboards. |
| **Network Perimeter & Identity** | **Cloud Run v2 (`terraform/main.tf`)**, dedicated least-privilege service account (`scouts-bsa-agent-sa`), **Secret Manager** (`BSA_API_KEY`, `BSA_HITL_SECRET_KEY`, `ADMIN_SUPERUSER_TOKEN`), and dual-mode Admin Super-User authentication (`verify_admin_superuser()`). | Organization-level **VPC Service Controls (VPC-SC)** perimeters, **Customer-Managed Encryption Keys (CMEK)**, and **Workforce Identity Federation** with Scouting America national my.scouting.org OIDC (blocked in standalone Argolis projects). |
| **Submission Bundle (`< 30 MB`) vs. `1.2 GB` Media Cache** | Live app and Cloud Run container bake in all **`3,917` visual assets (`1.2 GB`)**. For the `< 30 MB` `go/capstone-app` portal upload (`repo.bundle`, `10.19 MB`), `scripts/build_submission_bundle.py` writes `data/asset_inventory_manifest.json` and **`src/tools/asset_hydrator.py` (`ensure_badge_assets_hydrated()`)** batch-fetches any missing badge PNGs concurrently (`8` workers, `~950ms` cold, `0ms` cached) from GitHub Raw on demand. | Global **Cloud CDN + Google Cloud Storage (`gs://scouts-bsa-media-cdn`)** signed asset bucket for multi-council static media distribution. |

## 3. Rubric Item A4 Log: AI-Assisted Engineering Harness & Bugs Caught (`FM-1` through `FM-4`)

| Iteration / Failure ID | What the Coding Agent Initially Got Wrong | How Our Harness (`AGENTS.md` / `pytest` / `run_eval.py`) Caught It | Architectural Fix & Regression Gate Added |
| :--- | :--- | :--- | :--- |
| **`FM-1` (ADK Tool Conflict)** | Combined Vertex AI's built-in `GoogleSearchTool` and custom Python function tools on the same `LlmAgent`, triggering `400 INVALID_ARGUMENT` in production. | Caught by integration test and structured `tool_outcome` telemetry inspection. | Wrapped `WebSearchGroundingAgent` inside an ADK `AgentTool` boundary (`src/agents/researcher.py`, `ADR-01`) and added schema conformance tests in `tests/test_conformance_and_a2ui.py`. |
| **`FM-2` (Slide Overflow & White Boxes)** | Generated fixed `18pt` body text that overflowed bottom slide margins on dense requirements and rendered white rectangular backgrounds around scanned pamphlet figures on cream slides. | Caught by Stage 1 `<10ms` AABB geometry checker (`check_pptx_conformance()`) and Stage 2 visual auditor (`audit_deck_visual_quality()`). | Built proactive line-wrapping font auto-fit (`12.0pt` floor, `_compute_fitting_font_size()`) and border flood-fill alpha de-boxing (`_strip_white_image_background()` in `src/tools/pptx_builder.py`). |
| **`FM-3` (Synthetic Emblem Hallucination)** | Generated synthetic circular SVG/PNG placeholders instead of authentic Scout Shop embroidered merit badge patches. | Caught by automated visual dimension and hash verification (`scripts/verify_144_emblems.py`). | Verified all 144 authentic `400x400` Scout Shop embroidered patch PNGs (`assets/badge_emblems/*.png`) and locked their SHA-256 inventory in `data/asset_inventory_manifest.json`. |
| **`FM-4` (Single-Screen Presenter Friction)** | Relied only on a browser `window.open()` popup for the speaker teleprompter, which failed under strict popup blockers or single-laptop classroom projection. | Caught during live demo choreography rehearsal and Playwright UI verification. | Engineered the in-stage **Full-Size Split-Screen Presenter View (`P`)** alongside the `BroadcastChannel`-synced floating teleprompter (`ui/app.js`). |
