## 3. Rubric Item A4 Log: AI-Assisted Engineering Harness & Bugs Caught (`FM-1` through `FM-4`)

| Iteration / Failure ID | What the Coding Agent Initially Got Wrong | How Our Harness (`AGENTS.md` / `pytest` / `run_eval.py`) Caught It | Architectural Fix & Regression Gate Added |
| :--- | :--- | :--- | :--- |
| **`FM-1` (ADK Tool Conflict)** | Combined Vertex AI's built-in `GoogleSearchTool` and custom Python function tools on the same `LlmAgent`, triggering `400 INVALID_ARGUMENT` in production. | Caught by integration test and structured `tool_outcome` telemetry inspection. | Wrapped `WebSearchGroundingAgent` inside an ADK `AgentTool` boundary (`src/agents/researcher.py`, `ADR-01`) and added schema conformance tests in `tests/test_conformance_and_a2ui.py`. |
| **`FM-2` (Slide Overflow & White Boxes)** | Generated fixed `18pt` body text that overflowed bottom slide margins on dense requirements and rendered white rectangular backgrounds around scanned pamphlet figures on cream slides. | Caught by Stage 1 `<10ms` AABB geometry checker (`check_pptx_conformance()`) and Stage 2 visual auditor (`audit_deck_visual_quality()`). | Built proactive line-wrapping font auto-fit (`12.0pt` floor, `_compute_fitting_font_size()`) and border flood-fill alpha de-boxing (`_strip_white_image_background()` in `src/tools/pptx_builder.py`). |
| **`FM-3` (Synthetic Emblem Hallucination)** | Generated synthetic circular SVG/PNG placeholders instead of authentic Scout Shop embroidered merit badge patches. | Caught by automated visual dimension and hash verification (`scripts/verify_144_emblems.py`). | Verified all 149 authentic `400x400` Scout Shop embroidered patch PNGs (`assets/badge_emblems/*.png`) across `143` Active Official badges, `5` Test Lab Pilots, and `1` Discontinued Historical badge, and locked their SHA-256 inventory in `data/asset_inventory_manifest.json`. |
| **`FM-4` (Single-Screen Presenter Friction)** | Relied only on a browser `window.open()` popup for the speaker teleprompter, which failed under strict popup blockers or single-laptop classroom projection. | Caught during live demo choreography rehearsal and Playwright UI verification. | Engineered the in-stage **Full-Size Split-Screen Presenter View (`P`)** alongside the `BroadcastChannel`-synced floating teleprompter (`ui/app.js`). |
