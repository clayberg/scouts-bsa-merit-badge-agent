## 1. Problem statement, user personas, and critical user journeys

### 1.1 The volunteer counselor problem
Across Scouting America, volunteer Merit Badge Counselors teach **144 official Merit Badges** (including Eagle-required badges like *First Aid*, *Weather*, and *Emergency Preparedness* and STEM electives like *Robotics* and *Nuclear Science*). Preparing a complete teaching packet from an 80-page BSA Merit Badge Pamphlet takes a volunteer **6 to 10 hours** per badge. Existing ad-hoc slide decks shared online frequently teach outdated requirement revisions (causing problems at Eagle Scout Boards of Review), omit sub-requirements (`1a`, `1b`, `2a`), or fail to separate classroom discussion items from hands-on patrol skill stations and campout prerequisites.

### 1.2 Target user personas

| Persona | Role and context | Core need |
| :--- | :--- | :--- |
| **Volunteer Merit Badge Counselor** *(Primary User)* | Working parent or subject-matter professional teaching a badge across three 45-minute troop meetings or a Saturday Merit Badge University clinic. | A ready-to-teach `16:9` PowerPoint deck, speaker notes, printable Scout workbook, Quartermaster gear checklist, Blue Card sign-off matrix, and Youth Protection (YPT) parent prerequisite letter in under 2 minutes with zero missing sub-requirements. |
| **Council Advancement Chair / Camp Director** *(Enterprise Buyer)* | Oversees summer camp instruction and district Merit Badge clinics across 100+ troops. | Verifiable adherence to current official requirements, *Guide to Safe Scouting* policies, and Youth Protection (YPT) rules at a predictable cost (`~$0.18` actual cold LLM spend per generated packet, capped at `$1.00`). |
| **Youth Scout (Ages 11 to 17)** *(Downstream Beneficiary)* | Tenderfoot through Life Scout working toward advancement (`Tenderfoot 11-12`, `Mixed Troop 11-17`, or `Older Scouts / Eagle Prep 14-17`). | High-contrast visual diagrams, step-by-step procedures, and a clear checklist showing which requirements are completed in class versus at home or on a troop campout. |

## 2. Technical scope, system boundaries, and prototype vs. production matrix

### 2.1 System boundaries and hard architectural invariants

1. **Official pamphlet immutability (zero requirement drift)**: External web search and local troop grounding are never permitted to alter official requirement numbers or wording. `compute_canonical_pamphlet_hash()` (`src/agents/researcher.py`) computes a SHA-256 digest over the canonical `(req_number, req_text)` requirement tree (`canonical_fidelity_verified=True`) before and after enrichment.
2. **Vertex AI tool-mixing isolation**: Vertex AI and Google ADK reject requests that mix native `GoogleSearchTool` grounding and custom Python `FunctionTool` declarations on the same `LlmAgent`. We isolate web search inside `WebSearchGroundingAgent` (`gemini-2.5-flash`) and expose it to `PamphletResearchAgent` via an ADK `AgentTool` wrapper (`src/agents/researcher.py`).
3. **BSA Youth Protection (YPT), Pre-LLM PII redaction, and isolated counselor profile caching**: Counselor email addresses and phone numbers are never transmitted to external LLM endpoints, written to SQLite telemetry, or exported to Cloud Logging or Cloud Trace. On a local laptop, counselor details are cached in `.cache/counselor_profile.json` (`0600` owner-only permissions, git-ignored) so the counselor only enters them once; in multi-tenant Cloud Run (`K_SERVICE` / `IS_CLOUD_RUN=true`), server-side profile file caching is disabled and counselor info is stored in the user's browser `localStorage` (`scouts_bsa_counselor_profile_v1`). During execution, PII is scrubbed pre-LLM in `before_model_guardrail_callback()` (`src/agents/guardrails.py`) using `scrub_pii_before_sink()` (`[REDACTED_EMAIL]`, `[REDACTED_PHONE]`) and injected locally onto Cover Slide 1 and the Parent Letter by `pptx_builder.py` after LLM processing finishes.
4. **Dual FinOps Consent Gates for on-demand AI image generation (`$0.08/image`) and speaker-note AI polish (`$0.000835/slide`)**: While all 3,917 built-in visual assets and baseline `[SAY]`/`[DEMO]`/`[ASK]` teaching scripts are delivered at `$0.00`, on-demand cloud generation is protected by two explicit FinOps gates:
   - **Layer A1 (Custom Image Consent Gate)**: `NanoBananaImageAgent` (`src/agents/image_studio.py`) calculates an upfront cost estimate (`$0.08 USD` per image, ~`2,580` tokens across generation and verification) via `POST /api/v1/slide/estimate-image-cost` and blocks synthesis (`status="CONSENT_REQUIRED"`) unless `user_consented=True` is provided. After generation, `verify_generated_image_matches_prompt()` checks subject alignment and verifies zero rendered prompt instructions.
   - **Layer A2 (Speaker Notes AI Polish FinOps Gate)**: `POST /api/v1/slide/estimate-polish-cost` calculates exact `gemini-2.5-flash` (`thinking_budget=0`) token and USD costs (`~450` input tokens at `$0.30/1M` + `~280` output tokens at `$2.50/1M` = `$0.000835/slide`, or `$0.00` for slides already cached in the SQLite `polished_speaker_notes` table) and surfaces them in `#ai-polish-finops-modal` before running `POST /api/v1/slide/polish-notes` or `POST /api/v1/slide/polish-notes-batch`.

### 4.1 Location and ZIP code grounding (`resolve_counselor_location()`)
When a counselor enables **Local Troop Grounding** and supplies a `location_or_zip` value (such as `01949` or `Middleton, MA`, or a browser timezone fallback like `America/New_York`), `resolve_counselor_location()` (`src/agents/researcher.py`) maps the input across all 51 U.S. jurisdictions (50 states + D.C. via `_STATE_CIVIC_AND_FIELD_REGISTRY` in `src/tools/local_grounding_engine.py`) to a structured regional profile:
- **Regional NOAA NWS Forecast Office** (for example, `NOAA NWS Boston/Norton (BOX)` for `01949`).
- **Regional weather and terrain hazards** (for example, `Coastal Nor'easters, rapid cold-front shifts, winter hypothermia, and woodland Ixodes tick habitats`).
- **Local outdoor training venues and agencies** (for example, `Harold Parker State Forest, Blue Hills Reservation` and `MEMA & DCR State Parks`).
- **Current U.S. Senators and official contact portals** (`GET /api/v1/local-grounding/senators` and `POST /api/v1/admin/senators/refresh`).

To keep slides clean and free of repetitive footer text, this regional profile is injected into four specific places: **Slide 2 (Badge Overview)**, the **Counselor Session Lesson Plan**, the **Parent Prerequisite Letter**, and the **Grounded Citations** list.

### 4.2 Unified Warm Cream visual theme, modern & backward-compatible `beautification_tier` API (`WARM_CREAM`, `CRISP_WHITE`, `DARK_SLATE`), 3,917 pre-bundled visual assets, and In-App Documentation Viewer
