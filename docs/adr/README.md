# Architecture decision records index (`docs/adr/`)

All nine Architecture Decision Records (ADRs) for the Scouts BSA Merit Badge Counselor Workbench are documented in [`../../ARCHITECTURE_DECISIONS.md`](../../ARCHITECTURE_DECISIONS.md) and summarized below:

| ADR ID | Decision | Options evaluated | Chosen approach and trade-off |
| :--- | :--- | :--- | :--- |
| **ADR-01** | **Agent pipeline topology** | 1. Single-prompt monolith<br/>2. Unbounded peer graph<br/>3. ADK `SequentialAgent` + `LoopAgent` + `AgentTool` | **Option 3**: Wraps `GoogleSearchTool` inside `AgentTool` to avoid Vertex AI tool-mixing errors and caps review retries at 3 iterations. |
| **ADR-02** | **Pamphlet grounding and memory** | 1. Full 80-page PDF prompt stuffing<br/>2. Web-only RAG<br/>3. Hybrid pamphlet vector memory + SHA-256 lock | **Option 3**: Cuts input tokens by 68% while guaranteeing zero requirement drift via `compute_canonical_pamphlet_hash()`. |
| **ADR-03** | **Slide layout verification** | 1. Vision LLM on every slide<br/>2. No post-build check<br/>3. Stage 1 `<10ms` AABB math + Stage 2 Vision | **Option 3**: Catches shape overlaps and font-floor violations in memory in `<10ms` at `$0.00` token cost before running curriculum review. |
| **ADR-04** | **Youth Protection, counselor PII & Zero-PII telemetry** | 1. Raw PII in prompts<br/>2. Omit contact info<br/>3. Pre-LLM scrubbing + `ZeroPiiTelemetryStore` (`scrub_pii_dict()`) + local `.pptx` injection | **Option 3**: Scrubs emails and phones in `before_model_guardrail_callback()` and `ZeroPiiTelemetryStore` so PII never reaches external LLMs, SQLite telemetry, or Cloud Trace. |
| **ADR-05** | **Human-in-the-loop build gate** | 1. Unchecked execution<br/>2. Boolean tool flag<br/>3. HMAC-SHA256 `HITLConfirmationToken` | **Option 3**: Signs `badge_name` and `slide_count` with `BSA_HITL_SECRET_KEY` and verifies the token in `before_tool_callback`. |
| **ADR-06** | **Slide polish tiers, pre-populated hero graphics, and FinOps cap** | 1. AI image on every slide (`>$2.60`)<br/>2. Plain white slides / procedural-only boxes<br/>3. 3-tier polish + `3,917` built-in curated visual assets (`1,306` pre-populated Nano Banana PNGs + `2,323` 100%-Vision-verified BSA Pamphlet figures [`1,009` primary + `1,314` alternates] + `144` emblems + `144` covers across all 144 badges) + EDGE fallback + `FinOpsBudgetPlugin($1.00)` | **Option 3**: Offers `$0.14` (`STANDARD`), `$0.38` (`BEAUTIFIED`), and `$1.00` (`STUDIO`) tiers with pre-populated & Vision-verified graphics (`~426 MB` compressed) and never overwrites existing technical diagrams. |
| **ADR-07** | **Easy Slide Image Switcher, Image Studio catalog, Admin Catalog Studio, `Auto (Content-Aware Mix)`, `include_humans`, and `$0.08` consent gate** | 1. Overwrite graphic in place & clear all on reset<br/>2. Static read-only graphics<br/>3. `original_diagram_path` snapshot + `slide_image_choices` Easy Slide Image Switcher + `badge_image_catalog` + Super-User Admin Catalog Studio (`docs/ADMIN_GUIDE.md`) + 10 UI styles (`Auto (Content-Aware Mix)`) + `include_humans` + `$0.08` consent gate | **Option 3**: Enables 1-click on-stage cycling across Vision-verified pamphlet alternates (`◀` / `(1/3) ▾` / `▶`), tracks zero-PII swap telemetry for 1-click admin primary promotion, preserves original and hero graphics on cache clear, supports `$0.00` local uploads and 12-result Wikimedia search, and enforces a `$0.08` consent + prompt verification check for Nano Banana. |
| **ADR-08** | **Authentication, Super-User Admin auth & resilience** | 1. Mandatory JWT on laptop<br/>2. Open Cloud Run ingress<br/>3. `verify_caller_auth` + `verify_admin_superuser` + `CircuitBreaker` fallback | **Option 3**: Enforces `AUTH_REQUIRED=true` and VPC/WAF in Cloud Run, dual-mode Super-User Admin auth (`verify_admin_superuser()`), and zero-config local laptop runs. |
| **ADR-09** | **Unified FastAPI Material 3 Counselor Workbench & Admin Console** | 1. Dual Streamlit (`:8501`) + FastAPI (`:8085`) UIs<br/>2. Streamlit only<br/>3. Unified FastAPI Material 3 Counselor Workbench (`src/server.py` + `ui/`, `79` OpenAPI 3.1 endpoints) | **Option 3**: Retires the secondary Streamlit script and consolidates all 59 pytest tests, 3 construction animations, Dual-Window Presenter View (`P`), Fullscreen stage (`F`), Live Timer, Quiz Reveal, Easy Slide Image Switcher, 3-Tab Under-Stage Drawer, 4-Sub-Tab StudioKit, 3x5 Pocket Cue Cards, and Zero-PII Super-User Admin Console (`docs/ADMIN_GUIDE.md`) onto a single responsive workbench. |
